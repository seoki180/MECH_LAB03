MECHLab 실험 관리 프로그램
================================

폴더 구성
---------

  MECHLab/
    MECHLab.exe     실행 파일
    maps/           지도 타일팩(.mbtiles)을 넣는 폴더
    nmea/           재생할 GPS 로그(.nmea)를 넣는 폴더
    .mechlab/       프로그램이 자동으로 만드는 저장 폴더 (시험 목록, 측정 기록)

지도 타일팩과 NMEA 로그는 실행 파일 안에 들어 있지 않습니다. 파일 하나가 수백 MB에서
1 GB를 넘어 실행 파일에 넣을 수 없고, 구역을 추가할 때 프로그램을 다시 받지 않아도
되도록 바깥 폴더에서 읽습니다.

시작하기
--------

1. maps 폴더에 .mbtiles 타일팩 파일을 넣습니다. 여러 개 넣으면 모두 함께 사용합니다.
   타일팩이 없어도 프로그램은 실행되며, 지도 배경 없이 좌표와 궤적만 표시합니다.
2. nmea 폴더에 재생할 .nmea 로그를 넣습니다. 10km_log.nmea가 있으면 그 파일을
   먼저 사용하고, 없으면 이름순으로 첫 파일을 사용합니다. 로그가 없으면 내장 데모
   센서로 실행됩니다.
3. MECHLab.exe를 실행합니다.

처음 실행할 때 나오는 Windows 경고
----------------------------------

'Windows에서 PC를 보호했습니다' 또는 '신뢰할 수 없는 앱' 경고가 나옵니다. 코드
서명 인증서가 없는 프로그램은 모두 이 화면을 거칩니다. '추가 정보' → '실행'을
누르면 됩니다.

인터넷에서 받은 zip은 파일마다 차단 표시가 붙어, 압축을 푼 뒤에도 경고가 반복될
수 있습니다. 다음 순서로 없앱니다.

1. zip 파일을 마우스 오른쪽 → 속성 → 아래쪽 '차단 해제' 체크 → 확인.
2. 그 다음에 압축을 풉니다.

실행했는데 창이 안 뜰 때
------------------------

프로그램은 시작할 때마다 실행 파일 옆에 기록을 남깁니다.

  MECHLab-시작로그.txt   정상적으로 시작했을 때의 경로와 안내
  MECHLab-오류.txt       시작하지 못했을 때의 원인

창이 뜨지 않으면 이 두 파일을 확인하고, 없으면 프로그램이 실행 자체를 못 한
상태(백신 차단, 차단 해제 안 됨)입니다. 오류 내용은 창으로도 함께 표시됩니다.

자료를 다른 위치에 두기
-----------------------

지도 팩을 공용 드라이브에 두고 여러 PC가 같은 폴더를 보게 하려면 환경 변수를
설정합니다.

  MECHLAB_MAP_PACK   지도 타일팩 폴더
  MECHLAB_NMEA       재생할 .nmea 파일 (폴더가 아니라 파일 경로)
  MECHLAB_DATA_DIR   저장 폴더
  MECHLAB_HOME       위 세 가지의 기준 폴더를 한 번에 옮길 때

명령 프롬프트에서 실행 인자로 지정할 수도 있으며, 인자가 환경 변수보다 우선합니다.

  MECHLab.exe --map-pack "D:\공용\maps" --nmea "D:\공용\nmea\10km_log.nmea"

현재 경로 확인
--------------

프로그램이 어느 폴더를 보고 있는지 확인하려면 명령 프롬프트에서 실행합니다.

  MECHLab.exe --print-paths

지도가 표시되지 않을 때 이 출력의 map_pack_dir 경로에 .mbtiles 파일이 있는지
확인하세요.

참고
----

화면의 '데모' 표시는 실제 센서 대신 NMEA 파일을 재생하고 있다는 뜻입니다.
