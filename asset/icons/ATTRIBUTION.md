# 헤더 아이콘 출처

헤더 버튼은 `<command key>.svg` 또는 `<command key>.png`가 있으면 아이콘을 표시한다(단색, 라벨 색으로 재색상, SVG 우선). 없으면 글자만 표시한다.

모든 아이콘은 **Uicons by Flaticon** (https://www.flaticon.com/uicons), Regular Rounded 스타일이다. Flaticon 무료 라이선스에 따라 출처 표기가 필요하다.

- PNG: Flaticon 아이콘 페이지의 512 px PNG(`cdn-icons-png.flaticon.com`)를 받은 것
- SVG: Flaticon 공식 npm 패키지 `@flaticon/flaticon-uicons@3.3.1`의 regular-rounded 웹폰트 글리프를 SVG path로 변환한 것 (사이트 접근이 차단되어 대체 경로 사용)
